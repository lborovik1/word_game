# Scripts

Python scripts for building and maintaining
the word game data files.

## Requirements

- Python 3 (managed with `uv`)
- `anthropic` package (for Claude API scripts)
- `ANTHROPIC_API_KEY` environment variable set

## Scripts

### build_dictionary.py

Downloads the top 18,000 most frequent English
words and translates them to Russian using the
Claude API (Haiku model).

- Downloads frequency list from GitHub
- Translates in batches of 400 words
- Saves to `master_dictionary.json`
- Supports resume: skips already-translated words
- Cost-efficient: uses Claude Haiku

**Usage:**
```bash
python scripts/build_dictionary.py
```

### cleanup_dictionary.py

Removes bad entries from the master dictionary:
- Non-English words (la, el, de, etc.)
- Untranslated words (English = Russian)
- Single-character words
- Non-alphabetic entries
- Archaic/informal words (ye, gonna, etc.)
- Contraction fragments (doesn, isn, etc.)

**Usage:**
```bash
python scripts/cleanup_dictionary.py
```

### generate_games.py

Reads the master dictionary and generates 6
CEFR-level game files in the `games/` folder.

- Downloads frequency list for word ordering
- Creates cumulative level files (A1 through C2)
- Output: JSON files with English-Russian pairs

**Usage:**
```bash
python scripts/generate_games.py
```

### generate_test_questions.py

Expands test question pools from 10 to 100
variants per slot using the Claude API.

- Reads existing pool files in `mytests/`
- Generates new variants matching the same
  format, difficulty, and question type
- Validates all generated questions
- Saves updated pool files

**Usage:**
```bash
python scripts/generate_test_questions.py
```

### download_dictionary.py

Alternative dictionary builder (unused).
Kept for reference.

## Data Files

### master_dictionary.json

The master English-Russian dictionary with
~18,000 word pairs. Source of truth for all
game files. Generated by `build_dictionary.py`
and cleaned by `cleanup_dictionary.py`.

## Typical Workflow

1. Build the dictionary (one-time, ~$2 API cost):
   ```bash
   python scripts/build_dictionary.py
   ```

2. Clean up bad entries:
   ```bash
   python scripts/cleanup_dictionary.py
   ```

3. Generate game files:
   ```bash
   python scripts/generate_games.py
   ```

4. Expand test questions (optional):
   ```bash
   python scripts/generate_test_questions.py
   ```
